Folder Structure

How the codebase is organized. The app uses Angular feature modules (NgModules) rather than standalone components.

Key concepts

Feature modules

Each functional area has its own NgModule (elements.module.ts, charts.module.ts, and so on) that declares its page components and imports SharedModule. SharedModule re-exports the common Angular, Bootstrap, and Font Awesome modules so feature modules stay lean.

Layouts

BaseLayoutComponent is the full dashboard shell (header, sidebar, footer) used for dashboard routes. PagesLayoutComponent is a minimal shell for the authentication pages. The documentation section ships its own layout, independent of both.

Routing

Top-level routes live in app-routing.module.ts. Dashboard pages are registered eagerly via components.barrel.ts, while the documentation section is lazy-loaded under /docs so it stays out of the initial bundle.

State management

Theme configuration is held in an NgRx store under ThemeOptions/store/. Shared UI flags (sidebar toggles, hover state) live in theme-options.ts as Angular signals for zoneless reactivity.
