Build & Tooling

The template builds and serves with @angular/build — Angular's standalone Vite + esbuild pipeline. There is no webpack in the dependency tree.

Build system

Every angular.json target uses the @angular/build builders:

  • Dev server runs on Vite with fast HMR (ng serve).
  • Production builds use esbuild (ng build).
  • Bundle budgets are enforced: 2 MB warning / 5 MB error for the initial bundle.

Linting

ESLint 10 with flat config (eslint.config.js) using angular-eslint and typescript-eslint:

Run it with ng lint.

Testing

Unit tests run on Karma + Jasmine via @angular/build:karma, in a zoneless test setup. Run them with ng test (add --watch=false --browsers=ChromeHeadless for CI).

Keeping the build on @angular/build means no webpack/webpack-dev-server, faster cold starts, and a clean npm audit. See the Changelog for the migration details.
