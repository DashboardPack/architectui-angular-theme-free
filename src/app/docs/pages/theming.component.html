Theming

Styling is SCSS layered on top of Bootstrap 5.3.8, plus runtime header and sidebar theme switching through the NgRx config store.

SCSS organization

Bootstrap is imported from node_modules (no vendored copy) using the layered ordering — functions → overrides → variables → maps → mixins → utilities → components. Put your customizations in the override partials, not in the Bootstrap source.

Runtime header & sidebar themes

The header and sidebar accept a CSS class applied from the NgRx config store. Update them through ConfigService:

Any Bootstrap background utility works as a theme value, for example:

  • bg-primary
  • bg-success
  • bg-info
  • bg-warning
  • bg-danger

The sidebar binds the stored value directly, e.g. [class]="'app-sidebar ' + (config$ | async)?.sidebarTheme", so the change applies reactively.

Header/sidebar theme values are persisted in the NgRx store — see State & Signals.
