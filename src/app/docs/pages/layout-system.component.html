Layout System

The template ships two layout shells. Routes choose a shell by nesting under it as a parent component.

The two layouts

LayoutUsed forIncludes
BaseLayoutComponent Dashboard / app pages Header, sidebar, footer
PagesLayoutComponent Auth pages (login, register, …) Minimal — no sidebar or header

Both live in src/app/Layout/. The documentation section ships its own layout, separate from both.

Choosing a layout in routes

Layout components

The shared chrome lives under src/app/Layout/Components/: header, sidebar, footer, and page-title (the gradient heading used at the top of each page).

Responsive sidebar & signals

Sidebar and header behavior is driven by Angular signals in the ThemeOptions service. Because the app is zoneless, these signals are what trigger UI updates — there is no zone.js change detection.

The sidebar automatically collapses below 1200px. See State & Signals for how signals and NgRx divide responsibilities.
