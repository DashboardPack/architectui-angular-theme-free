Getting Started

Install dependencies, run the dev server, and create a production build.

Prerequisites

  • Node.js ^20.19, ^22.12, or >=24 (22.x LTS recommended — see .nvmrc)
  • npm (bundled with Node) or yarn
  • Angular CLI 21+ — optional globally; the local CLI is used via npm run / npx
