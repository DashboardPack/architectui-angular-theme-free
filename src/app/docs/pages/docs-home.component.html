ArchitectUI Angular — Documentation

A modern, zoneless Angular 22 admin dashboard template built with Bootstrap 5, Chart.js, and NgRx. This guide covers installation, project structure, deployment, and release notes.

Tech stack

AreaTechnology
FrameworkAngular 22 (zoneless, NgModule-based)
UIBootstrap 5.3.8 + SCSS
IconsFont Awesome 7, Pe7 Stroke icons
ChartsChart.js 4 via ng2-charts 10
StateNgRx Store 21
Build / dev server@angular/build (Vite 7 + esbuild) — no webpack
LintingESLint 10 (flat config)
LanguageTypeScript 6.0
